# GD Wordle

A Wordle-style word-guessing game with a built-in speed leaderboard, built for a booth/event setting where players compete to solve the word in the shortest time.

## Setup / How to Run

- Clone this repository to your computer.
- Open `index.html` in any modern web browser — no installation or server required.
- Play a round; winning submits your nickname and time to the on-page leaderboard (saved locally in the browser).
